# Lalita Sahasranama - Interactive Learning Website

## Project Context
- Interactive website for learning Sri Lalita Sahasranama (1000 sacred names of Divine Mother Lalita Tripurasundari)
- Live at https://thehardikdewra.github.io/lalita-sahasranama/
- Repo: https://github.com/TheHardikDewra/lalita-sahasranama
- Pure vanilla HTML/CSS/JS, no frameworks, no build step
- Data is embedded in data.js, generated by build_data.py

## Sacred Text - Handle With Care
- This is deeply sacred content for Hindu devotees. Accuracy is non-negotiable.
- Every Sanskrit name, transliteration (IAST), and meaning must be verified against the Obsidian source files before any change
- Source of truth: `/Users/hardikdewra/Documents/Obsidian Vault/Metta/05 - Spirituality & Sadhana/Lalita Sahasranama/`
- 10 files: `Sri Lalita Sahasranama - 001 - 100.md` through `901 - 1000.md`
- Master index with verse structure: `0 Sri Lalita Sahasranama Stotram 0.md`
- NEVER guess or fabricate Sanskrit text, meanings, or spiritual commentary

## The 83 Remaining Names (918-1000) Without Commentary
- Names 918-1000 currently have no detailed commentary (empty string in data.js)
- The Om Swami Ji Telegram community (https://t.me/OmSwamiJi, topic 24408 "Sri Lalita Sahasranama") has been posting commentaries since June 2023
- As of March 2026, they've reached name 917
- The channel is still active and will eventually cover all 1000 names
- To update with new commentaries:
  1. Run the Telegram export: `cd ~/lalita-sahasranama && source .venv/bin/activate && python3 export_telegram.py`
  2. This fetches ALL messages and parses name posts into telegram_names_detailed.json
  3. Then run: `python3 build_data.py` to regenerate data.js with new commentaries
  4. The export script uses Telethon (Telegram API). Session is cached in lalita_session.session
  5. API credentials are in export_telegram.py (DO NOT commit this file - it's in .gitignore)
- When integrating new names, verify each commentary matches the correct name number
- The channel posts follow this format: #Name NNN, Sanskrit, Transliteration, then detailed explanation
- Some posts are combined (two names in one message) - the parser handles this but check edge cases

## Data Pipeline
- Source data: Obsidian markdown files (all 1000 names with Sanskrit, IAST, meanings)
- Telegram data: telegram_names_detailed.json (915 commentaries with full text)
- Telegram links: Also from telegram_names_detailed.json (917 links) + fallback from the HTML file
- Verse mapping: verse_name_mapping.json (182 verses, which names belong to each)
- Build script: build_data.py reads all sources and generates data.js
- 5 compound names were split to reach the full 1000 count (defined in COMPOUND_SPLITS in build_data.py)

## Design Rules
- NO gradients. NO glowy effects. Solid flat colors only.
- NO linear-gradient, radial-gradient, box-shadow glows, or text-shadow glows
- Fonts: Haffer (local) > Geist > Inter for body; Tiro Devanagari Sanskrit for Sanskrit headings
- Dark theme with warm gold accent (#c9a84c)
- Card designs: Tag/label strip for name cards, straight left bar for home cards, full border outline for flashcards

## File Structure
- `index.html` - Main page, SPA with hash routing
- `style.css` - All styles, dark theme, mobile responsive
- `app.js` - Application logic (IIFE wrapped)
- `data.js` - Generated data file (DO NOT edit manually - regenerate via build_data.py)
- `build_data.py` - Data merge script (reads Obsidian + Telegram + verse mapping, outputs data.js)
- `export_telegram.py` - Telegram message exporter (has API credentials, in .gitignore)
- `manifest.json` - PWA manifest
- `sw.js` - Service worker for offline support
- `.gitignore` - Excludes venv, session files, export scripts

## Key Architectural Decisions
- Single page app with hash routing (#home, #names, #verses, #practice, #name/NUMBER)
- Lazy rendering with IntersectionObserver for the 1000 name cards (batches of 80)
- localStorage for progress (learned names) and spaced repetition data
- No server needed - fully static, works offline via service worker
