# Sri Lalita Sahasranama

Interactive guide to the 1000 sacred names of the Divine Mother Lalita Tripurasundari - built for seekers learning to chant and understand the Lalita Sahasranama Stotra.

**Live site**: [hardikdewra.github.io/lalita-sahasranama](https://hardikdewra.github.io/lalita-sahasranama/)

## What's inside

- **1000 divine names** with Sanskrit (Devanagari), IAST transliteration, and English meanings
- **915 detailed commentaries** sourced from [Om Swami Ji's](https://t.me/OmSwamiJi) Telegram community
- **1000 individual mantras** (Om [name] Namah format)
- **182 verses** - the full stotra arranged verse-by-verse for chanting
- **5 dhyana (meditation) verses** with translations
- **Phala Shruti** - closing verses and colophon
- **Chanting audio** links to popular recordings

## Features

### Chant
Full-screen teleprompter mode for daily recitation. Large Devanagari text, auto-advance with configurable speed, fullscreen API, keyboard navigation (arrows, space, F), optional transliteration and meanings overlay. Remembers your position between sessions.

### Home
Stats dashboard, sadhana tracker (log recitations, track streaks), daily name, expandable dhyana verses, phala shruti, audio links, quick navigation.

### Names
Browse all 1000 names with search, range filters, and learned/unlearned filtering. Click any name to expand and see: detailed commentary, mantra, verse context, Telegram link, and space for personal notes. Deep links (#name/42) for sharing specific names.

### Verses
Navigate verse-by-verse through all 182 slokas. Each verse shows the full Devanagari text with individual name breakdowns. Mark entire verses as learned. Progress bar tracks completion.

### Practice
Flashcard mode with spaced repetition (SM-2 algorithm). Two directions: Sanskrit-to-Meaning and Meaning-to-Sanskrit. 18 verse-range scopes plus "Due Today" for SRS review. Keyboard shortcuts: Space to flip, G for "got it", R for "review again".

## Seeker tools

- **Sadhana tracker** - log recitations, track daily streaks and monthly counts
- **Progress tracking** - mark names as learned, spaced repetition for review scheduling
- **Personal notes** - add your own reflections to any name (gold dot indicator)
- **Font size controls** - A-/A+ for readability
- **Export/Import** - backup and restore all your progress as JSON
- **Installable PWA** - works offline, add to home screen on mobile
- **Print-friendly** - clean layout for printing names and verses

## Data sources

- **Names, transliterations, meanings**: Extracted from structured Obsidian notes based on traditional commentaries
- **Verse structure**: Parsed from the original stotra text (Brahmanda Purana, Uttara Khanda - dialogue between Sri Hayagriva and Agastya)
- **Detailed commentary**: Exported from the "Sri Lalita Sahasranama" topic in the Om Swami Ji Telegram community (4973 messages, 915 name posts)
- **Dhyana verses**: From the stotra preamble with IAST transliteration and English translation

## Tech

Pure vanilla HTML/CSS/JS - no frameworks, no build step. Works offline via service worker.

- Fonts: Haffer (local), Geist, Inter for body; Tiro Devanagari Sanskrit for headings
- Dark theme, flat design (no gradients/glows), mobile responsive
- All progress persisted in localStorage
- Spaced repetition uses the SM-2 algorithm
- Data embedded in `data.js`, generated by `build_data.py`

## Running locally

```bash
python3 -m http.server 9000
# visit http://localhost:9000
```

## Source text

The Sri Lalita Sahasranama is from the Brahmanda Purana. The stotra was narrated by Sri Hayagriva to Sage Agastya. It contains 1000 names of the Divine Mother arranged in 182 slokas, preceded by dhyana verses for meditation.

This project is a devotional offering to Maa Lalita Tripurasundari.
